# Arnav & Ankita Wedding
GitHub Pages target: https://erishita.github.io/arnav-ankita-wedding/

The RSVP is connected to Formspree endpoint `https://formspree.io/f/xjywkwan`.

## Publish
1. Create public repository `arnav-ankita-wedding` under GitHub user `erishita`.
2. Upload the contents of this package to repository root.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Test the published site on phone and desktop.
5. Submit one test RSVP and verify it reaches the Formspree dashboard / configured email before sharing.
